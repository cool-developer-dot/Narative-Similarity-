METHOD 1: OVERLEAF (RECOMMENDED - EASIEST!)
================================================================================

Overleaf is a FREE online LaTeX editor. No installation needed!

STEPS:
------
1. Go to: https://www.overleaf.com/

2. Click "Register" (or "Log In" if you have account)
   - Use your university email for extra features

3. Click "New Project" → "Upload Project"

4. Create a ZIP file with these files:
   - assignment3_report.tex
   - architecture_diagram.pdf
   - plots/model_comparison.pdf (after you generate plots)
   - plots/training_curves.pdf
   - plots/confusion_matrix_proposed.pdf
   - plots/error_analysis.pdf
   - plots/improvement.pdf

5. Upload the ZIP to Overleaf

6. Click "Recompile" button → PDF appears on right side!

7. Edit your names in lines 13-18:
   Change: Student 1, Student 2, Student 3, Student 4
   To: Your actual names

8. Change: Your University Name
   To: Your actual university

9. Click "Recompile" again

10. Download PDF: Menu → Download → PDF

DONE! ✅

TIME: 5 minutes
COST: Free
DIFFICULTY: ★☆☆☆☆ (Very Easy)


================================================================================
METHOD 2: INSTALL MIKTEX (For Local Compilation)
================================================================================

If you want to compile LaTeX on your computer:

STEPS:
------
1. Download MiKTeX installer:
   https://miktex.org/download
   
   Click: "Download" → Windows → 64-bit installer

2. Run the installer:
   - Choose "Install MiKTeX for all users" (recommended)
   - Use default settings
   - Wait 5-10 minutes (downloads ~300 MB)

3. Restart your PowerShell/Terminal

4. Navigate to your project folder:
   cd "C:\Users\mfara\Desktop\Assignment 3"

5. Compile the report:
   pdflatex assignment3_report.tex
   bibtex assignment3_report
   pdflatex assignment3_report.tex
   pdflatex assignment3_report.tex

   (Yes, you run pdflatex 3 times - this is normal!)

6. Open the generated PDF:
   assignment3_report.pdf

DONE! ✅

TIME: 15 minutes (including installation)
COST: Free
DIFFICULTY: ★★★☆☆ (Medium)

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: "Missing packages" error in Overleaf
SOLUTION: Overleaf auto-installs packages. Just wait or click Recompile.

PROBLEM: "File not found: plots/model_comparison.pdf"
SOLUTION: Make sure you ran: python evaluate_results.py --plot
          Then upload all generated plots to Overleaf.

PROBLEM: "Citation undefined" warnings
SOLUTION: Normal! Click Recompile 2-3 times. Warnings will disappear.

PROBLEM: MiKTeX installer is slow
SOLUTION: Use Overleaf instead (Method 1). It's faster!
